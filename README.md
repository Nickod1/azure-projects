# Azure Cloud Engineering Projects

A collection of hands-on Microsoft Azure projects focused on
cloud infrastructure, networking, identity, security, automation,
monitoring, DevOps, and architecture.

The projects progress from core Azure infrastructure engineering
toward designing and automating enterprise cloud environments.

## Projects

### 01. Enterprise Azure Networking

Designed and deployed a segmented hub-and-spoke Azure network
with separate Production and Development environments.

**Technologies:** Azure Virtual Networks, VNet Peering, NSGs,
Azure Bastion, Private DNS, Route Tables, Network Watcher

**Key areas:** Network architecture, segmentation, private
administration, routing, DNS, and troubleshooting.
